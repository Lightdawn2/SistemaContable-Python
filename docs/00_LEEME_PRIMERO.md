## 🚀 CÓMO USAR AHORA

### Los Estudiantes Hacen:
```
1. Abren Sistema Contable
2. Registran asientos
3. Menú → "📊 Exportar a Excel"
4. Seleccionan carpeta
5. Entregan archivo al profesor
```

### Los Profesores Hacen:
```
1. Reciben archivo Excel del estudiante
2. Abren "Resumen Evaluación"
3. Ven si dice "CUADRADO" → Está bien
4. Revisan otras hojas si necesitan detalles
5. Califican en 15-20 minutos
```
