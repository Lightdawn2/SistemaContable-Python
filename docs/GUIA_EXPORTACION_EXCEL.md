# GUÍA: EXPORTACIÓN A EXCEL - SISTEMA CONTABLE EDUCATIVO

## Descripción General

Este sistema incluye una funcionalidad completa de exportación de datos contables a **archivos Excel profesionales** listos para evaluación. Es la solución ideal para profesores que necesitan revisar el trabajo de estudiantes sin requerir conocimiento técnico en programación.

---

## Para Estudiantes: Cómo Exportar tu Trabajo

### Paso 1: Prepara tu Trabajo
- Registra todos los comprobantes y asientos contables en el sistema
- Asegúrate de que el Plan de Cuentas esté correctamente estructurado
- Verifica que tus débitos y créditos cuadren

### Paso 2: Exporta a Excel
1. En el **menú principal** del Sistema Contable
2. Haz clic en el botón **"📊 Exportar a Excel"**
3. Selecciona la carpeta donde guardar el archivo
4. Dale un nombre significativo (ej: `Contabilidad_Grupo2_Noviembre.xlsx`)
5. ¡Listo! El archivo se generará automáticamente

### Paso 3: Entrega
- El archivo Excel estará listo para entregar a tu profesor
- Puedes abrirlo con Microsoft Excel, LibreOffice Calc o Google Sheets
- No requiere ningún software especial

## Para Profesores: Cómo Evaluar

### Contenido del Archivo Excel

El archivo generado contiene **7 hojas de trabajo** organizadas para facilitar la evaluación:

#### 1. **RESUMEN DE EVALUACIÓN** (Primera hoja)
- **Propósito**: Visión rápida del trabajo del estudiante
- **Qué contiene**:
  - Fecha de generación
  - Cantidad de cuentas registradas
  - Cantidad de comprobantes
  - Total de asientos contables
  - **Estado de Cuadre**: Indica si el trabajo está balanceado
  - **Validación de Integridad**: Verifica si Débitos = Créditos

**Cómo leer**: 
- Si el **Estado de Cuadre** dice "CUADRADO" → El trabajo está bien estructurado
- Si dice "NO CUADRA" → Hay errores en los asientos

#### 2. **PLAN DE CUENTAS**
- **Propósito**: Evaluar la estructura contable del alumno
- **Qué contiene**:
  - Código de cada cuenta
  - Nombre de la cuenta
  - Elemento (Activo, Pasivo, Patrimonio, Ingreso, Costo, Gasto)
  - Categoría y Subcategoría
  - Grupo

**Cómo evaluar**:
- Verifica si la clasificación es correcta
- Comprueba que hay cuentas apropiadas para el tipo de negocio/ejercicio
- Evalúa si la estructura es lógica y educativamente correcta

#### 3. **COMPROBANTES**
- **Propósito**: Ver todos los asientos registrados
- **Qué contiene**:
  - Número del comprobante
  - Fecha
  - Descripción (glosa)
  - Para cada línea: Código cuenta, Nombre, Debe, Haber
  - Totales automáticos de Debe y Haber
  - Indicador de cuadre

**Cómo evaluar**:
- Revisa si los asientos tienen sentido contablemente
- Verifica que cada comprobante cuadre (Debe = Haber)
- Comprueba si la descripción es clara

#### 4. **LIBRO DIARIO**
- **Propósito**: Visualizar los asientos en orden cronológico
- **Qué contiene**:
  - Datos organizados por fecha
  - Orden secuencial de todos los movimientos
  - Totales acumulativos

**Cómo evaluar**:
- Revisa el orden temporal de los registros
- Verifica la coherencia de los asientos
- Comprueba totales automáticos

#### 5. **BALANCE DE COMPROBACIÓN**
- **Propósito**: Verificar la igualdad fundamental de la contabilidad
- **Qué contiene**:
  - Todas las cuentas
  - Total Debe de cada cuenta
  - Total Haber de cada cuenta
  - Saldo Deudor (si Debe > Haber)
  - Saldo Acreedor (si Haber > Debe)
  - **Validación automática** de cuadre

**Cómo evaluar**:
- El **BALANCE DEBE CUADRAR** siempre
- Suma de Débitos = Suma de Créditos
- Si no cuadra, hay errores en los asientos

#### 6. **ESTADO DE SITUACIÓN** (Hoja 6)
- **Propósito**: Evaluar la estructura de la posición financiera
- **Qué contiene**:
  - ACTIVO (total)
  - PASIVO (total)
  - PATRIMONIO (total)
  
**Cómo evaluar**:
- Verifica la ecuación fundamental: **Activo = Pasivo + Patrimonio**
- Comprueba que los saldos sean coherentes

#### 7. **ESTADO DE RESULTADOS** (Hoja 7)
- **Propósito**: Evaluar la comprensión del ciclo de ingresos y gastos
- **Qué contiene**:
  - Total Ingresos
  - Total Costos
  - Total Gastos
  - **RESULTADO NETO** (Utilidad o Pérdida)
  
**Cómo evaluar**:
- Verifica que los ingresos, costos y gastos sean razonables
- Comprueba el cálculo del resultado neto
- Evalúa si el resultado tiene sentido para el ejercicio

## Criterios de Evaluación Sugeridos

### Estructura Contable (25%)
- ✓ Plan de cuentas bien organizado
- ✓ Cuentas clasificadas correctamente
- ✓ Coherencia de la estructura

### Integridad de Datos (25%)
- ✓ Balance de Comprobación cuadra
- ✓ Todos los comprobantes cuadran
- ✓ Débitos = Créditos totales

### Registro de Asientos (30%)
- ✓ Comprobantes registrados correctamente
- ✓ Cantidades y montos exactos
- ✓ Descripciones claras (glosa)

### Comprensión Conceptual (20%)
- ✓ Clasificación lógica de gastos e ingresos
- ✓ Estado de Resultados coherente
- ✓ Relación entre elementos financieros

## Preguntas Frecuentes

**P: ¿Puedo editar el archivo Excel después de exportarlo?**
R: Sí, pero se recomienda no modificarlo para mantener integridad auditoria.

**P: ¿Qué hago si el Balance no cuadra?**
R: Revisa el Libro Diario para encontrar el asiento con error.

**P: ¿Cómo genero un nuevo archivo si cambio datos?**
R: Simplemente exporta nuevamente. Sobrescribe el anterior.

**P: ¿El sistema guarda el histórico de exportaciones?**
R: No, cada exportación es nueva. Guarda manualmente si necesitas comparar.
